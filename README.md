# Plateforme de jeux multijoueurs en réseau (TD n°3)

Projet individuel de « Compléments Java » : une plateforme client-serveur Java 21 / Maven / JUnit permettant à des joueurs situés sur des machines différentes de se trouver, de s'inviter et de jouer ensemble.

La documentation complète (démarrage rapide, protocole, UDP/TCP, concurrence, ajout d'un jeu) est en cours de rédaction.
